# 척척 에셋

부동산 자산운용을 기초학습 → 모의투자 → 가정 수립 → 시나리오 판단으로 연습하는 교육용 앱입니다.

[척척 에셋 열기](https://ckhckj2.github.io/cheokcheok-asset/)

- 20강, 쉬운 설명, 네 줄 요약, 순차 해금과 복습
- 단원·종합 퀴즈, 해설, 오답 복습, 명시적 승급
- 대리: 투자 조건 비교와 판단 복기
- 과장: 가상 비교 자료로 임대료·공실률·운영비 가정 수립
- 팀장: 금리·공실·공사비·매각 Cap Rate 시나리오와 전략 비교
- 내 레벨 → 관리자 모드로 보기: 실제 진도를 바꾸지 않는 공개 콘텐츠 검토

## 개발 및 검증

먼저 [AGENTS.md](AGENTS.md)를 읽습니다. 소스는 `source/`, GitHub Pages 배포 파일은 루트 `index.html`입니다. Node.js와 Python 3 외에 추가 패키지는 필요하지 않습니다.

```sh
python3 source/check.py
```

자동 검증 6개 묶음을 실행하고, 배포 HTML을 빌드한 뒤 CSP 해시와 정적 화면 연결을 확인합니다. 문구나 스타일만 바꾸면 영향 범위에 필요한 검사를 선택하고 `python3 source/build.py`로 빌드합니다. 검증 내역과 제한은 [검증 기록](VERIFICATION.md)에 남깁니다.

## 데이터와 모델 범위

로그인·서버·자동 동기화 없이 해당 기기의 브라우저 저장소에 기록합니다. 관리자 모드는 계정 관리 권한이 아니며 검토 기록은 메모리에만 남습니다. 브라우저 데이터를 지우면 실제 학습 기록도 사라집니다.

모든 사례와 시나리오는 교육용 가정입니다. 실제 시세 조회, 자동 전망, 실제 투자 주문 기능은 없습니다. 과거 기록의 계산 조건과 저장 키는 유지합니다. 손상되거나 지원하지 않는 기록은 자동 덮어쓰기하지 않고 이번 방문의 메모리 기록으로 진행합니다.
